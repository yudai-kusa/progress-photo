# 進捗フォト

筋トレの進捗写真をスマホで撮りためて見比べる Web アプリ(PWA)です。

- 写真とタグは **端末内(IndexedDB)にだけ保存** され、外部のサーバーには送信されません
- ビルド不要・外部ライブラリなし。GitHub Pages にそのまま置いて動きます
- ホーム画面に追加すると、オフラインでも起動できます

## 機能

| 画面 | できること |
|---|---|
| 一覧 | 部位・ポーズで絞り込み、日付順(新しい順/古い順)に月ごとに表示 |
| 撮影 | アプリ内カメラ。タグを選ぶと同じタグの直近の写真を半透明で重ねて表示(写真の変更・濃さ調整可)。逆さ撮りモード、セルフタイマー、カメラ切り替え(背面・前面) |
| 追加 | アルバムから選択(複数可)。日付は写真の撮影日を自動で入れ、変更もできる。前回のタグを自動で選択 |
| 詳細・編集 | 日付とタグの付け替え、削除 |
| 比較 | 上に固定写真、下は左右スワイプで切り替え。「固定写真から◯日後」を表示。「これを固定」で入れ替え、「同じポーズのみ」で絞り込み |
| タグ管理 | 部位・ポーズのタグの追加・名前変更・削除・並び替え |
| 設定 | バックアップ(ZIP)の作成・保存、バックアップからの復元(追加 / 置き換え)、使用容量の表示 |

## 使い方(Android)

1. Chrome で公開 URL を開く
2. 画面上部に出る「インストール」ボタン、または Chrome 右上のメニュー(⋮)→「ホーム画面に追加」/「アプリをインストール」
3. ホーム画面のアイコンから起動して使う

バックアップは「設定 → バックアップを作成 → ファイルとして保存」で端末の「ダウンロード」フォルダに ZIP が保存されます。スマホの故障や紛失に備えて、Google ドライブなどにもアップロードしておくと安心です。

## 使い方(iPhone)

1. Safari で公開 URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. **ホーム画面のアイコンから起動して使う**

> Safari とホーム画面のアプリでは保存場所が別々です。Safari で追加した写真は、ホーム画面のアプリには表示されません。

写真はアプリを削除したりブラウザのデータを消すと消えます。ときどき「設定 → バックアップを作成 → 保存・共有する →『"ファイル"に保存』」で iCloud Drive などに保存してください。

## GitHub Pages で公開する

1. このリポジトリの **Settings → Pages** を開く
2. Source を「Deploy from a branch」、Branch を公開したいブランチ(例: `main`)の `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/progress-photo/` で開けるようになります

## 手元で動かす

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## 構成

```
index.html / manifest.webmanifest / sw.js
css/style.css
js/
  app.js       起動・画面の切り替え
  nav.js       画面遷移と戻る操作
  db.js        IndexedDB のラッパー
  store.js     状態管理(タグ・写真の読み書き)
  image.js     縮小(長辺2048px)・サムネイル生成・EXIF の撮影日読み取り
  backup.js    バックアップ ZIP の書き出し/読み込み
  ui.js        ダイアログ・トースト
  swiper.js    横スワイプの部品
  views/       各画面(list, photo, editor, compare, camera, tags, settings)
```

### データ

- `photos`: `{ id, date, partTagIds[], poseTagId, thumb, width, height, createdAt }`
- `images`: `{ id, blob }`(大きい画像。必要なときだけ読む)
- `tags`: `{ id, type: 'part' | 'pose', name, order }`
- `meta`: 最終バックアップ日時など

### バックアップ ZIP の中身

```
data.json          タグと写真のメタ情報
photos/<id>.jpg    写真
thumbs/<id>.jpg    サムネイル
```

### 更新時の注意

Service Worker は「キャッシュから即表示 → 裏で最新版を取得 → 次回起動で反映」の動きです。
ファイルを追加・削除したときは `sw.js` の `ASSETS` も更新し、`CACHE` の名前の番号を上げてください。
